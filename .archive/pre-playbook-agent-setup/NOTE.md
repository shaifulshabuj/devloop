# Archived — pre-playbook agentic setup

These files were this project's **own** agent-control scaffolding, written before the org adopted a
single canonical contract. They are archived rather than deleted because they are part of the work
history and record how this project governed its agents at the time.

**They are no longer in force.** Agent behaviour is now governed by the Agentic Playbook rules block in
`AGENTS.md` (marker `PLAYBOOK-BLOCK v13`), whose canonical source is
`dna-concept/01-agent-rules-block.md`. If something here is still needed, promote it into the canonical
block and re-propagate — do not re-activate it locally, or the copies drift again.

Archived 2026-08-27 by GPM.
